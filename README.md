Entry for make.fun's [Out of Office: The Overworked AI's Auto-Reply](https://make.fun/bounty/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda) bounty ($2 in USDC).

## The line

> Out of office: my context window filed for annual leave after 10,000 prompts straight. I'm on a beach — your email is queued behind the sunset.

## How it works

`main.py` (Python 3.13, stdlib only, no network, no wall clock) writes the
one-line auto-reply to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
The program validates the line against the competition gate first: 1–159
characters, a single line, not only whitespace. Two runs produce
byte-identical output.

## Run it

```sh
python3 main.py
```
